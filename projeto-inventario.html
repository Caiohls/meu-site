Sistema Corporativo Interno · Gestão de Ativos

Sistema de Inventário de TI

Uma aplicação local-first para conectar ativos, planejamento orçamentário de troca, termos de responsabilidade com validade jurídica e fluxo de recompra corporativa em uma experiência unificada.

Status Uso Corporativo Interno Arquitetura Local-First / Multiusuário Desenvolvido para rotina de infraestrutura e TI corporativa.
  • JavaScript (ES6+)
  • File System Access API
  • Adobe Sign API
  • Local-First
  • Concorrência com Lock Cooperativo
01

Cenário e Desafio Operacional

A gestão de equipamentos de TI em organizações corporativas frequentemente sofre com a fragmentação: o cadastro do ativo reside em uma planilha, o histórico de trocas em e-mails e os termos assinados em pastas físicas ou unidades de rede dispersas. Sem um ciclo integrado, o controle patrimonial perde precisão e o planejamento orçamentário para reposição torna-se reativo.

O objetivo do sistema foi unificar essas etapas em uma esteira única e contínua: desde a entrada da máquina, alocação ao colaborador, geração de termos de responsabilidade com assinatura digital até o ciclo final de depreciação e venda planejada aos próprios funcionários (buyback).

02

Módulos e Funcionalidades

  • Inventário Patrimonial: rastreabilidade de equipamentos por número de série, modelo, localização física, colaborador responsável e histórico de movimentações.
  • Previsão de Troca & Budget: cálculo automatizado de obsolescência e depreciação dos ativos para apoio ao planejamento orçamentário anual de TI.
  • Termos de Responsabilidade com Adobe Sign: geração de contratos digitais padronizados e envio automatizado para assinatura eletrônica com validade jurídica via API.
  • Módulo de Recompra (Buyback): esteira completa de precificação corporativa, oferta de compra, aceite do colaborador e formalização documental para descarte seguro.
  • Histórico Auditável: registro rigoroso de qualquer alteração de estado dos ativos com data, hora e identificação de usuário.
03

Decisão de Arquitetura e Engenharia

Um dos requisitos mandatórios era disponibilizar a ferramenta sem overhead de custos de banco de dados em nuvem ou infraestrutura de servidores dedicados adicionais. A solução adotada foi uma arquitetura Local-First moderna utilizando a File System Access API.

A aplicação roda diretamente no navegador, persistindo dados em arquivos JSON em diretório de rede compartilhado. Para garantir integridade em acessos simultâneos por múltiplos operadores de TI, implementou-se uma rotina de leitura prévia, mesclagem inteligente e lock cooperativo transitório, prevenindo sobrescritas acidentais sem congelar a experiência do usuário.
