01

Visão Computacional · Otimização de Performance

AnáliseIA — Otimização de Inferência de Vídeo

Uso Corporativo Interno

Pipeline de Aceleração

Entrada Vídeo → Python Pipeline → OpenVINO Toolkit → Intel Arc GPU
~50 min tempo original de processamento para ~3 min de vídeo
~1 min após adaptação e aceleração em hardware (-98%)

Evolução e otimização de uma aplicação de análise de vídeo com modelos de visão computacional. O desafio central foi portar uma solução concebida para Linux/NVIDIA para execução eficiente no parque corporativo Windows com GPU dedicada Intel Arc.

01

Problema de Negócio

O tempo de espera excessivo (~50 min para analisar 3 min de gravação) inviabilizava a rotina de inspeção operacional.

02

Restrição Técnica

Necessidade de operar na infraestrutura padrão da empresa (ambiente Windows) aproveitando a GPU Intel Arc disponível.

03

Solução de Engenharia

Reestruturação do pipeline em Python com OpenVINO, eliminando gargalos de decodificação de frames e inferência paralela.

04

Impacto Gerado

Redução drástica do ciclo de análise para cerca de 1 minuto, tornando a ferramenta viável para uso diário contínuo.

  • Python
  • OpenVINO
  • Visão Computacional
  • Intel Arc
  • Otimização de Hardware

Código proprietário e modelos protegidos por confidencialidade corporativa.

04

SaaS Multi-tenant · Produção

GerenteEvent

SaaS Concluído

Plataforma SaaS multi-tenant que substitui o controle manual de eventos corporativos por um fluxo completo: gestão de workspaces, convites por token único, credenciamento via QR Code com scanner e certificados em PDF.

Problema de Negócio
Eventos empresariais recorrentes enfrentam gargalos no credenciamento, falta de histórico de participantes e emissão manual de certificados.
Decisão de Engenharia
Frontend reativo em React 19 + Vite, banco de dados PostgreSQL com RLS no Supabase, envio transacional via Brevo e Edge Functions serverless.
  • React 19
  • Vite
  • TypeScript
  • Supabase / Postgres
  • Edge Functions
  • Tailwind CSS

05

Aplicação Web · Inteligência Comercial

CalculaMeta

Deploy Ativo

Aplicação focada em ritmo de vendas diário (pacing), decompondo metas mensais estáticas em indicadores acionáveis de rotina para antecipar desvios operacionais antes do fechamento do mês.

Problema de Negócio
Avaliar o cumprimento da meta apenas no encerramento do mês impossibilita intervenções preventivas na cadência de vendas.
Decisão de Engenharia
Arquitetura Next.js 16 com App Router, projeção matemática baseada em dias úteis trabalhados, funções RPC atômicas no Supabase e pipeline CI no GitHub Actions.
  • Next.js 16
  • React 19
  • TypeScript
  • Supabase Postgres
  • Tailwind CSS
  • GitHub Actions
