## Projetos Selecionados

### 01. AnáliseIA — Otimização de Inferência de Vídeo
Evolução e otimização de uma aplicação de visão computacional. O desafio foi portar uma solução concebida para Linux/NVIDIA para execução eficiente no parque corporativo Windows com GPU dedicada Intel Arc, utilizando Python e o toolkit OpenVINO.

Em um cenário de referência, cerca de 3 minutos de vídeo levavam aproximadamente 50 minutos para serem processados. Com a reestruturação do pipeline e inferência acelerada em hardware, o tempo caiu para cerca de **1 minuto** (redução de 98%), tornando a rotina de inspeção viável para uso diário contínuo.

`Python` · `OpenVINO` · `Intel Arc` · `Visão Computacional` · `Otimização de Hardware`  
*Projeto de uso corporativo interno; código protegido por confidencialidade.*

### 02. Sistema de Inventário de TI
Sistema corporativo interno para gestão unificada do ciclo de vida de ativos de TI: controle patrimonial, cálculo de depreciação e budget anual de reposição, geração de termos com assinatura eletrônica via Adobe Sign API e módulo de recompra de equipamentos por colaboradores (buyback).

Arquitetura local-first em JavaScript puro com a **File System Access API**, operando em rede compartilhada com controle de concorrência por leitura prévia, mesclagem e lock cooperativo.

`JavaScript` · `File System Access API` · `Adobe Sign API` · `Local-First` · `Multiusuário`  
*Projeto de uso corporativo interno; código sanitizado.*
