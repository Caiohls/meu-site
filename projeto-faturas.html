Sistema Corporativo Interno · Esteira Fiscal

Gestão de Faturas por Filial

Uma aplicação corporativa para lançar, importar, conciliar e rastrear faturas recebidas por diferentes filiais operacionais, estabelecendo uma ponte estruturada e confiável com o departamento fiscal central.

Status Uso Corporativo Interno Arquitetura Local-First / Multiusuário Desenvolvido para coordenar o fluxo operacional e fiscal entre unidades.
  • JavaScript (ES6+)
  • File System Access API
  • Importação de Planilhas
  • Multiusuário Concorrente
  • Templates de Conciliação Fiscal
01

Cenário e Gargalo Operacional

Em operações com filiais distribuídas geograficamente, o recebimento físico e digital de faturas de fornecedores frequentemente gerava desalinhamento entre o polo operacional e o setor fiscal. Notas chegavam com prazos curtos de vencimento, aprovações pendentes em e-mails e ausência de uma visão unificada sobre o status de cada lançamento.

O sistema foi concebido para dar transparência instantânea à esteira de contas a pagar: qual filial recebeu o documento, qual é o fornecedor, se há pendência de validação operacional e qual é a etapa exata de escrituração no fiscal.

02

Entregáveis e Funcionalidades

  • Lançamento Ágil & Edição: cadastro centralizado de faturas por mês de competência, filial de origem, fornecedor, valor e status de conformidade.
  • Importação em Lote: ingestão estruturada de dados a partir de planilhas operacionais e pastas de rede com validação de duplicidade.
  • Fluxo de Conciliação Fiscal: painel dedicado para a equipe fiscal marcar pendências, devoluções e aprovações com preenchimento automatizado de modelos de e-mail padronizados.
  • Gestão de Recorrências: cadastro de fornecedores com despesas fixas recorrentes, reduzindo o tempo de lançamento nos fechamentos mensais.
  • Painel de Indicadores: métricas consolidadas de volume financeiro por filial, quantidade de notas pendentes e distribuição por status.
03

Decisão Técnica e Concorrência

O sistema precisava rodar sem impor custos de infraestrutura de banco de dados ou barreiras de firewall entre filiais. A arquitetura escolhida operou em Local-First sobre a File System Access API, conectando as estações de trabalho diretamente a pastas compartilhadas de rede segura da organização.

Para suportar múltiplos operadores registrando faturas ao mesmo tempo, foi desenvolvido um protocolo cooperativo: antes de cada gravação, a aplicação verifica integridade de versão de arquivo, mescla entradas não conflitantes e notifica visualmente o operador caso outro usuário tenha atualizado o mesmo lote.
